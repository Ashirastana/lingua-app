# Lingua — мини-приложение для учебных Telegram-ботов

Испанский (`?lang=es`) и турецкий (`?lang=tr`). Открывается из ботов кнопкой «🎮 Играть».
Урок дня (5 шагов подряд), игры для повторения, очки, уровни и серия дней.
Прогресс хранится в Telegram (CloudStorage). Словари `es.json`, `tr.json` собираются из репозитория ботов.
Картинки — системные эмодзи.
